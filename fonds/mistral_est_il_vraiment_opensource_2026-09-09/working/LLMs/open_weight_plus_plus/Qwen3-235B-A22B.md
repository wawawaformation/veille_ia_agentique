# Qwen3-235B-A22B — Alibaba / Qwen

**Poids** : Apache 2.0  
**Licence** : Apache 2.0  
**Paramètres** : 235B total, ~22B actifs (128 experts, 8 actifs)  
**Entraînement** : ~36T tokens  
**Langues** : 119 + dialectes  

## Clé pédagogique
Qwen publie beaucoup de la recette : architecture, tokens utilisés, familles de données (Web, PDF, maths, code, synthétiques), préentraînement multi-étapes, post-entraînement (CoT, RL) documenté. Mais pas tous les ingrédients exacts pour refaire le modèle.
