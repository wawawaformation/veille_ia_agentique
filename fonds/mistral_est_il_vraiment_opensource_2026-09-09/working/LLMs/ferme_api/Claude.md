# Claude — Anthropic

**Poids** : Fermés (famille)  
**Licence** : Propriétaire (service)  
**Stratégie** : Service fermé uniquement  
**Accès** : API Anthropic + partenaires cloud  

## Clé pédagogique
Modèle d'« intelligence comme service » au niveau de la famille : l'utilisateur bénéficie de la famille Claude et des mises à jour, mais ne la possède pas. Contrairement à OpenAI, Anthropic n'a pas de branche parallèle ouverte.
