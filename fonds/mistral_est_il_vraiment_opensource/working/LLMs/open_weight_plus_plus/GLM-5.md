**Poids** : MIT (Hugging Face)  
**Code** : Apache 2.0 (GitHub)  
**Paramètres** : GLM-5.2 ≈ 744B MoE  
**Contexte** : jusqu'à 1M tokens (variantes coding)  

## Clé pédagogique
Zhipu communique sur GLM-5.2 comme **« fully open source »**. Les sources confirment
poids + code sous licences permissives, mais **aucune mention trouvée d'un dataset
d'entraînement publié** — contrairement à Nemotron ou OLMo.

> Bon exemple à ajouter aux cas Llama/DeepSeek déjà traités : la communication d'un éditeur
> ("fully open source") ne suffit pas à elle seule à confirmer la catégorie. En l'état des
> sources trouvées, GLM reste Open weight++, pas Open Source complet.

**Source** : catalogue Ollama Cloud, recoupé via blogs spécialisés — à vérifier sur
Hugging Face/GitHub avant restitution.
