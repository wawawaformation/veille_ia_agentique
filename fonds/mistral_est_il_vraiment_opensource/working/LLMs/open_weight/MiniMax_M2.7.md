# MiniMax M2.7 / M3 — MiniMax

**Poids** : Publiés  
**Licence** : **restreinte depuis M2.7** — usage personnel/recherche libre, déploiement
commercial nécessite une autorisation écrite préalable de MiniMax  
**Paramètres** : M2 ≈ 230B total / 10B actifs (MoE)  
**Historique** : M2 était sous MIT sans restriction  

## Clé pédagogique
Glissement de licence entre versions : MIT libre (M2) → autorisation commerciale requise
(M2.7). Mouvement inverse de ce qu'on attend d'un éditeur cherchant l'adoption.

> Parallèle direct avec Grok déjà noté dans la fresque : **l'histoire d'un éditeur n'est
> pas une progression linéaire vers davantage d'ouverture.** Grok le montre par génération
> de modèle ; MiniMax le montre par un durcissement de licence au fil des versions d'une
> même famille.

**Source** : Let's Data Science, HuggingFace discussions — à recouper avec la page de
licence officielle avant restitution.
